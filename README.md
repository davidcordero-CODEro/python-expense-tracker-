# Python Expense Tracker

This is another beginner Python project I made to practice my programming skills.

This project is a command line expense tracker that allows users to record expenses, manage their budget, and see how much money they have left.

## Features:

- Set a starting budget
- Add expenses with names and amounts
- Calculate remaining budget
- View total spending
- View expense history
- Prevent overspending
- Reject negative and zero expenses
- Interactive menu

## What I learned :)

- User input
- Floats and strings
- 'if', 'elif', and 'else' statements
- Nested if statements
- While loops
- For loops
- Lists and nested lists
- Using .append()
- F strings
- Basic debugging
